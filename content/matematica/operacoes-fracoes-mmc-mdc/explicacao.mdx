## 1. Ordem das operações

1. Parênteses, colchetes e chaves (de dentro para fora).
2. Potências e raízes.
3. Multiplicação e divisão (da esquerda para a direita).
4. Adição e subtração.

## 2. Frações

| Operação | Regra | Exemplo |
|---|---|---|
| **Soma e subtração** | Reduza ao **mesmo denominador** (MMC) | 3/4 + 1/6 = 9/12 + 2/12 = **11/12** |
| **Multiplicação** | Numerador × numerador, denominador × denominador | 2/3 × 3/5 = 6/15 = **2/5** |
| **Divisão** | Multiplique pelo **inverso** | 2/3 ÷ 4/5 = 2/3 × 5/4 = **5/6** |
| **Fração de um valor** | Multiplique | 2/5 de 150 = 2/5 × 150 = **60** |

Para verificar uma sobra: **1 − (soma das frações gastas)**. Se 1/3 vai para aluguel e 1/4 para alimentação: 1 − 4/12 − 3/12 = **5/12**.

## 3. Decimais

- Some e subtraia **alinhando a vírgula**.
- Na multiplicação, multiplique como inteiros e **some as casas decimais**: 0,75 × 0,4 = 0,30.
- Na divisão, multiplique dividendo e divisor por potência de 10 para eliminar a vírgula do divisor.

## 4. Potenciação e radiciação

**Potência:** aⁿ é a multiplicada por ela mesma n vezes. Vale também com **frações** e **decimais**: (2/3)² = 4/9; (0,2)² = 0,04; (1,5)² = 2,25.

| Propriedade | Regra | Exemplo |
|---|---|---|
| **Produto de mesma base** | Soma os expoentes | 2³ × 2² = 2⁵ = **32** |
| **Quociente de mesma base** | Subtrai os expoentes | 3⁵ ÷ 3² = 3³ = **27** |
| **Potência de potência** | Multiplica os expoentes | (2³)² = 2⁶ = **64** |
| **Expoente zero** | Qualquer base não nula dá 1 | 7⁰ = **1** |
| **Expoente negativo** | Inverte a base | 2⁻³ = 1/2³ = **1/8** |
| **Potência de fração** | Eleva numerador e denominador | (3/4)² = **9/16** |

Atenção aos sinais: (−2)² = **4**, mas −2² = **−4** (o expoente só vale para o 2). Base negativa com expoente **ímpar** dá resultado negativo: (−2)³ = −8.

**Raiz:** √a é o número que, elevado ao quadrado, dá a (com a ≥ 0). ³√a é a raiz cúbica.

- Raízes exatas comuns: √4 = 2, √9 = 3, √16 = 4, √25 = 5, √36 = 6, √49 = 7, √64 = 8, √81 = 9, √100 = 10, √144 = 12; ³√8 = 2 e ³√27 = 3.
- Raiz de **decimal e de fração**: √0,25 = **0,5**; √(9/16) = **3/4**; ³√(8/27) = **2/3**.
- **Simplificação:** √72 = √(36 × 2) = 6√2. A raiz do produto é o produto das raízes.
- A raiz **não distribui** sobre a soma: √(9 + 16) = √25 = 5, e não √9 + √16 = 7.

## 5. MMC e MDC

| | Ideia | Quando usar |
|---|---|---|
| **MMC** (menor múltiplo comum) | Menor número divisível por todos | **Coincidência** de eventos periódicos; somar frações |
| **MDC** (maior divisor comum) | Maior número que divide todos | **Dividir em grupos iguais**, maior tamanho possível, sem sobra |

Cálculo por **decomposição em fatores primos**: MMC = fatores comuns e não comuns **com maior expoente**; MDC = fatores **comuns com menor expoente**.

- MMC(12, 18): 12 = 2² × 3; 18 = 2 × 3² → MMC = 2² × 3² = **36**.
- MDC(48, 72): 48 = 2⁴ × 3; 72 = 2³ × 3² → MDC = 2³ × 3 = **24**.

## Armadilhas comuns

- Trocar **(−2)²** por **−2²**; somar os expoentes na **soma** de potências (2³ + 2² não é 2⁵); distribuir a raiz sobre a **soma**.
- Somar frações **somando denominadores**.
- Usar MDC quando o problema pede **coincidência** (é MMC).
- Esquecer a ordem das operações.
